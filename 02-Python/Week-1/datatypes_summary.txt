1. WHAT IS DATA?
----------------

Data is information that a computer stores, processes, or transfers.

Network Examples

Hostname
Management IP
Interface Name
VLAN ID
CPU Usage
Memory Usage
BGP ASN
Serial Number

Everything collected from a network device is data.

============================================================

2. WHY DO WE NEED DATA TYPES?
-----------------------------

Python must know what kind of data it is working with.

Example

100

is a number.

"100"

is text.

Without data types, Python would not know whether to
perform arithmetic or text operations.

============================================================

3. WHAT IS A DATA TYPE?
-----------------------

Definition

A data type tells Python what kind of data an object
contains and what operations can be performed on it.

Remember

Data Type belongs to the OBJECT,
not the variable.

============================================================

5. PRIMITIVE DATA TYPES
-----------------------

Python provides five basic data types.

------------------------------------------------------------
int
------------------------------------------------------------

Stores whole numbers.

Examples

vlan_id = 100

bgp_asn = 65001

ssh_port = 22

retry_count = 3

Network Use

VLAN IDs

BGP ASN

Port Numbers

Counters

------------------------------------------------------------
float
------------------------------------------------------------

Stores decimal values.

Examples

cpu_usage = 42.7

memory_usage = 78.4

temperature = 39.5

Network Use

CPU Utilization

Memory Usage

Temperature

Bandwidth Utilization

------------------------------------------------------------
bool
------------------------------------------------------------

Only two values

True

False

Examples

bgp_established = False

ssh_enabled = True

Network Use

Interface Status

Ping Success

Neighbor Status

Service Running

------------------------------------------------------------

------------------------------------------------------------

Stores text.

Examples

Network Use

Hostnames

IP Addresses

Interface Names

Device Models

Serial Numbers

------------------------------------------------------------
None
------------------------------------------------------------

Represents

"No Value"

Example

Difference

↓

↓

============================================================

6. WHY IS IP ADDRESS A STRING?
------------------------------

Python does not recognize

192.168.10.11

as an IP address.

It interprets dots as decimal separators.

Therefore

management_ip = "192.168.10.11"

is stored as text.

Later

Python's ipaddress module
can represent IP addresses as dedicated IP objects.

============================================================

7. COLLECTION DATA TYPES
------------------------

Collections store multiple values.

Python provides four main collections.

------------------------------------------------------------
List
------------------------------------------------------------

Ordered

Mutable

Duplicates Allowed

Example

devices = [
    "Leaf01",
    "Leaf02",
    "Leaf03"
]

Best For

Device Inventory

------------------------------------------------------------
Tuple
------------------------------------------------------------

Ordered

Immutable

Duplicates Allowed

Example

credentials = (
    "admin",
    "Cisco123"
)

Best For

Fixed Values

------------------------------------------------------------
Dictionary
------------------------------------------------------------

Key : Value pairs

Example

device = {
    "hostname":"Leaf01",
    "ip":"10.10.10.11"
}

Best For

Device Information

API Responses

JSON Data

Inventory

------------------------------------------------------------
Set
------------------------------------------------------------

Unordered

Mutable

Duplicates NOT Allowed

Example

vlans = {
    100,
    200,
    300
}

Best For

Unique VLANs

Unique Interfaces

Unique IP Addresses

============================================================

8. LIST OF DICTIONARIES
-----------------------

Wrong

{
"hostname":"Leaf01",
"hostname":"Leaf02"
}

Duplicate keys overwrite previous values.

Correct

[
 {
   "hostname":"Leaf01",
   "ip":"192.168.1.1"
 },
 {
   "hostname":"Leaf02",
   "ip":"192.168.1.2"
 }
]

This is the most common structure in Network Automation.

12. COMMON BEGINNER MISTAKES
----------------------------

❌ Using duplicate dictionary keys

❌ Storing VLAN IDs as strings

❌ Storing CPU usage as text

❌ Writing

"True"

instead of

True

❌ Writing

"None"

instead of

None

❌ Assuming IP addresses are numbers

13. BEST PRACTICES
------------------

✓ Choose the correct data type.

✓ Store IP addresses as strings.

✓ Store VLAN IDs as integers.

✓ Use dictionaries for device details.

✓ Use lists for inventories.

✓ Use sets when uniqueness matters.

✓ Use None instead of empty strings for unknown values.

✓ Check data types using type() while learning.
