1. WHAT IS A VARIABLE?
----------------------
A variable is a meaningful name (label) that refers to an object stored in memory.

Example:
device_hostname = "Leaf01"

Variable -> device_hostname
Object   -> "Leaf01"

Remember:
Variable is NOT the data.
Variable points to the data (object).

============================================================

2. WHAT IS AN OBJECT?
---------------------
Everything in Python is an object.

Examples:
String
Integer
Float
Boolean
List
Dictionary
Function
Class

Every object has:
1. Value
2. Type
3. Identity

Example:

device_hostname = "Leaf01"

Object
------
Value    : Leaf01
Type     : str
Identity : id()

============================================================

3. VARIABLES VS OBJECTS
-----------------------

device_hostname = "Leaf01"

Variable
   │
   ▼
Object ("Leaf01")

Variable = Label

Object = Actual data stored in memory

============================================================

4. MEMORY CONCEPT
-----------------

RAM

+---------------------------+
| Object : "Leaf01"         |
| Object : 100              |
| Object : True             |
+---------------------------+

Variables point to these objects.

============================================================

5. ASSIGNMENT OPERATOR (=)
--------------------------

Example:

hostname = "Leaf01"

Read as:

Assign "Leaf01" to hostname.

Do NOT read it as

hostname equals Leaf01

Assignment (=)

Comparison (==)

They are different.

============================================================

6. type()
---------

Returns object's data type.

Example:

hostname = "Leaf01"

print(type(hostname))

Output

<class 'str'>

Examples

type(100)

<class 'int'>

type(True)

<class 'bool'>

============================================================

7. id()
-------

Returns object's identity.

Example

hostname = "Leaf01"

print(id(hostname))

Output

140512345678912

Do not memorize the number.

Just know every object has a unique identity.

============================================================

8. DYNAMIC TYPING
-----------------

Python variables can refer to different object types.

Example

device = "Leaf01"

device = 100

device = True

Same variable

Different object

Different type

============================================================

9. REASSIGNMENT
---------------

Before

hostname

↓

"Leaf01"

After

hostname = "Leaf02"

hostname

↓

"Leaf02"

Variable now points to another object.
