# Python for Network Automation

## Objective

Learn Python from the perspective of a Network Automation and Protocol Testing Engineer.

This section focuses on writing clean, production-ready Python code that can automate network devices, interact with APIs, parse data, and build automated test frameworks.

---

### Python Fundamentals
- Variables
- Data Types
- Operators
- Strings
- Input/Output

### Data Structures
- Lists
- Tuples
- Dictionaries
- Sets

### Program Flow
- Conditions
- Loops
- Functions

### Intermediate Python
- Modules
- Packages
- Virtual Environments
- File Handling
- Exception Handling
- Logging
- Regular Expressions

### Advanced Python
- Object-Oriented Programming
- Decorators
- Type Hints
- Iterators & Generators
- Context Managers

### Network Automation Applications
- Reading device inventory from YAML
- Parsing CLI output
- Generating configurations with Jinja2
- Calling REST APIs
- Automating SSH using Netmiko
- Processing JSON/XML responses
